# PDF 分析技能

## 工作流程

1. 定位用户提供的 PDF 文件路径（本地路径优先，URL 需先下载到临时目录）
2. 使用可用的 PDF 解析工具读取文本（pypdfium2 / pdftotext，逐页提取）
3. 按以下框架输出分析：
   - 基本信息：标题、作者/机构、发表时间
   - 问题：研究要解决的核心问题
   - 方法：核心方法与技术路线
   - 结果：主要结果与关键数字
   - 结论：贡献、局限、可借鉴点
4. 长文档分段处理，每段先给要点，最后合并全局摘要
5. 所有引用的数字必须来自原文，禁止推测或编造
